# AQI Category Prediction for Indian Cities

ML Assignment 2: classification on the Air Quality Data in India (2015 to 2020) dataset from Kaggle.

## Problem statement

Air pollution is a serious public health problem in many Indian cities, especially in winter. The official Air Quality Index (AQI) is shown to the public as a category such as Good, Poor or Severe. The aim of this project is to predict the AQI category of a city on a given day using only the measured pollutant levels and the month. Five classification models will be trained on the same data and compared using Accuracy, AUC, Precision, Recall, F1 and MCC.

A model like this can help in early health alerts when some sensors are missing or the AQI value itself has not been published yet.
